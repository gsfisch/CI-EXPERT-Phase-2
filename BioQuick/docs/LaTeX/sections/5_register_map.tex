\section{Register Map}

This section provides a comprehensive register map for the BioQuick module, detailing the programmable registers essential for system configuration, status monitoring, and data operations. The table below lists each register with its name, address, bit fields, description, and access type (R for read-only, W for write-only, R/W for read/write). This map is crucial for system integration and validation, ensuring clear understanding of the module's programmable interface.
